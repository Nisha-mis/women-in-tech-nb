# Women in Tech NB

**Connect • Learn • Mentor • Grow**

Version 1 of the Women in Tech NB community website.

## V1 includes
- Responsive single-page community site
- Community, events, learning, mentorship, stories and career sections
- Join-community form with browser-only demo confirmation
- Mobile navigation
- New Brunswick-focused content and sample event cards

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the public Pages address when deployment completes.

## Next phase
